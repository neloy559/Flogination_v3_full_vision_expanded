# FLogination - The Session Manager: Technical Plan & Architecture

This document outlines the architecture, tools, and planned features for the FLogination project. 
It is designed to guide a Python developer in building high-performance automation components that interface with the existing Web/Electron suite.

---

## 🏗️ SYSTEM ARCHITECTURE OVERVIEW

The project is split into two primary layers to ensure stability and modularity:

1. **Frontend/Orchestrator (TypeScript/Next.js/Node)**:
   - Handles the UI, database (SQLite), and high-level session management.
   - Manages the "Agent Bridge" – an internal API for external tools.
   - Runs on Port 3000 (UI) and Port 3001 (API).

2. **Automation Layer (Python/Playwright)**:
   - The "Muscle" of the operation.
   - Responsible for stealth browser launches, fingerprinting, and complex FB actions (BM creation, friend scraping, etc.).
   - Communicates with the Orchestrator via the Agent Bridge API.

---

## 🛠️ PROPOSED TECH STACK (Automation Side)

- **Language**: Python 3.11+ (Type-hinted for reliability)
- **Browser Engine**: Playwright (superior to Selenium for Facebook's modern SPA architecture)
- **Stealth**: `playwright-stealth` + Custom Bezier Curve mouse movement logic.
- **Communication**: `httpx` or `requests` (for Agent Bridge interaction)
- **Packaging**: `PyInstaller` or `Nuitka` 
- **Data Handling**: `pandas` (for sessions.xlsx/csv processing)

## 🧩 MODULE BREAKDOWN

### 1. Browser Core (`modules/browser.py`)
- **Responsibility**: Launching Chromium with custom user profiles and proxies.
- **Features**: 
  - Fingerprint injection (Navigator, Canvas, WebGL).
  - WebRTC blocking.
  - Proxy-level authentication handling.
  - Stealth mode (Anti-bot detection bypass).

### 2. Interaction Engine (`modules/actions.py`)
- **Responsibility**: Human-like navigation.
- **Features**:
  - Bezier-based mouse paths (avoiding straight lines).
  - Randomized typing speeds and delays.
  - Visual-based detection (waiting for elements instead of hard-coded sleeps).

### 3. Agent Bridge Client (`modules/bridge.py`)
- **Responsibility**: Syncing status with the Orchestrator.
- **Tools**:
  - GET `/api/settings` to fetch global configs.
  - GET `/api/sessions` to see which accounts need checking.
  - POST `/api/logs` to report real-time progress back to the UI.

### 4. Facebook Automation Modules (`modules/fb/`)

This directory should contain specialized scripts for high-level tasks:

- **`bm_manager.py`**:
  - **Create BM**: Automated Business Manager creation.
  - **Ad Account Setup**: Auto-verifying and setting up initial ad accounts.
  - **Invite Link Gen**: Generating and extracting BM invitation links.

- **`page_factory.py`**:
  - **Create Pages**: Automated creation of FB Pages with category and profile selection.
  - **Bio/Info Setup**: Injection of profile pictures, covers, and "About" info.

- **`social_engine.py`**:
  - **Friend Requests**: Sending requests to targeted users and auto-accepting incoming ones.
  - **Interaction**: Intelligent commenting on posts (via custom URLs or inner feed scope).
  - **Liking/Sharing**: Warming up accounts through natural social activity.

- **`data_harvester.py`**:
  - **Profile Scraper**: Collecting deep info (Date of Birth, Friend Counts, Page Counts, BM Counts).
  - **Secondary Contact**: Extracting linked emails, phone numbers, and WhatsApp info where available.
  - **Export**: Syncing this harvested data back to the Orchestrator via the Agent Bridge.

## 🚀 CORE FEATURES & CAPABILITIES

### 1. Advanced Session Logic
- **Mass Launcher**: Launches multiple stealth windows in a precise grid pattern, synced with Web UI layout settings.
- **Smart Restorer**: Detects browser crashes or forced closures; automatically restarts and restores the session using cached cookies/session data.
- **Hibernation System**: Automatically suspends inactive browser contexts to save RAM, waking them instantly when user interaction is required.

### 2. Stealth & Anti-Detection
- **Dynamic Fingerprinting**: Injects unique Canvas, WebGL, AudioContext, and Font fingerprints for every session.
- **Human-Mimicry (HM-1)**: Uses Bezier curves for mouse movements and randomized "slop" in typing and click timing to bypass behavioral analysis.
- **WebRTC & IPv6 Masking**: Hard-blocks WebRTC leaks and prioritizes clean proxy tunnels for all outgoing traffic.

### 3. Facebook Automation Suite
- **Health Guard**: Real-time monitoring of account status (Live, Checkpoint, Disabled, or Restricted).
- **BM & Ad Management**: Automated Business Manager creation, ad account setup, and invitation link generation.
- **Scraping & Data Entry**: High-speed extraction of group members, friends lists, and automated profile warming.

### 4. Integration & Control
- **Agent Bridge Sync**: Full bi-directional sync with the TS Orchestrator. The Python engine reports every click and state change back to the main dashboard.
- **ADB Support**: Optional bridge for mobile-specific actions, allowing the tool to switch between Desktop and Mobile environments for higher trust scores.
- **Global Proxy Rotation**: Support for rotating residential proxies with per-session sticky-IP management.

---

## 💡 REASONING BEHIND TECH CHOICES

- **Playwright over Selenium**: Better support for CDP (Chrome DevTools Protocol), allowing deeper stealth patching and faster execution.
- **Separate Python Modules**: Allows the developer to update the "Health Checker" without touching the "Browser Launcher," minimizing bugs.
- **Agent Bridge Architecture**: Decouples the UI from the Automation. If the UI is closed, the Python bots can continue running in the background.

## 📜 DEVELOPER NOTES (Patterns to Follow)
- **Strict Error Handling**: Use `try/except` blocks extensively. Facebook updates often; the tool must fail gracefully without crashing.
- **Local Logs**: Maintain a `logs/` directory with detailed debug info for troubleshooting.
- **Modular Configs**: Use `.env` or `config.json` for API keys and global settings.
